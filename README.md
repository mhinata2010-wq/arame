# ARAME

毎朝 **07:00（端末のローカル時刻）** に鳴る、シンプルなブラウザ目覚ましアプリです。静的HTMLだけで動きます。

## 使い方

1. `index.html` をブラウザで開く（公開時はGitHub Pagesでも可）。
2. 「音を5秒テスト」で音が出るか確認し、端末の音量・出力先を調整する。
3. 「アラームを有効にする」を押す。
4. 可能なら「画面のスリープを防ぐ」を押し、ページを開いたまま電源に接続する。
5. 07:00に音声と赤い全画面表示が始まる。「起きた！」で止める。翌日も繰り返し。

## 重要な制約

- **絶対に起こすことは保証できません**。ブラウザの閉鎖、端末スリープ、バックグラウンド抑制、自動再生制限、音量ゼロ、Bluetooth出力先の切り替わりで失敗することがあります。
- 開発側が端末の音量を最大にすることはできません。安全のためWeb Audioの出力には上限を設けています。聴覚に負担のない範囲で音量テストしてください。
- 設定状態は端末のlocalStorageに保存しますが、閉じたブラウザを自動起動する機能はありません。ページを再読み込みした後は音声テストし直してください。
- 大切な朝には **OS標準の時計アプリで7:00の予備アラームを必ず設定** してください。
- 画面のスリープ防止は対応環境の画面表示中にのみ有効です。

## 蚊の羽音モード（デフォルト）
- 研究で報告されているヒトスジシマカ（Aedes albopictus）の雌の羽ばたき周波数は約500Hz前後。合成音では500Hzを基本に1,000Hzと1,500Hzの弱い倍音を加えています。
- 0.23Hzのゆっくりした音量変化で近づいたり遠ざかったりする動きを、微小な周波数変化と振幅変化で揺らぎを近似します。実際の蚊の録音ではありません。
- 17kHz前後の「モスキート音」とは異なり、耳元で聞く蚊の羽音を模したものです。
- 音が聞こえる大きさは機器ごとに異なります。安全のため音量をむやみに上げず、音声テストを小音量から始めてください。従来の警告音にも切り替えられます。
- 参考: [2025年の羽ばたき周波数測定研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12049413/) / [HumBugの研究](https://besjournals.onlinelibrary.wiley.com/doi/10.1111/2041-210X.13663)
- この合成音だけで起床できる保証はありません。

## 構成

- `index.html`: HTML/CSS/JavaScript。Web Audio API、Screen Wake Lock API、localStorage。
- ライブラリ・外部API・ユーザーデータ送信なし。

## 手動検証

- [ ] デスクトップとスマホ幅で表示が崩れない
- [ ] テスト音が5秒で止まり、途中停止もできる
- [ ] 有効化・解除の状態と画面表示が一致する
- [ ] localStorageに設定が保存され、再読み込み後に復元される
- [ ] 開いた状態で07:00になった際に鳴動し、停止すると止まる
- [ ] 翌日の07:00でも再鳴動する
- [ ] タブ閉鎖・スリープ時の制限が表示されている
- [ ] キーボード操作、フォーカス表示、縮小画面で動作する

テスト用に時刻ロジックを検証する場合はローカルの開発環境で端末時刻を変更し、別の重要なアラームと混同しないよう注意してください。
